# WorkTrace Marketing

Next.js App Router conversion of the Lovable/TanStack Start marketing-page export.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production check

```bash
npm run build
npm start
```

## Integration placeholders

The visual design has been preserved. Connect the Sign in, trial, demo, and contact-sales buttons to the WorkTrace application/auth routes when those URLs are finalized.
